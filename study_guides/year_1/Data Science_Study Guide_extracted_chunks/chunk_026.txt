Programming Language -  As a data scientist is it important that you have a sound understanding of 
the Python programming language (as prescribed by this module): So why choose Python? 
 
• Python is an extremely simple language to read and write, even if you've never coded before. 
• It is one of the most common languages for Data Science. 
• The language's online community is vast and friendly. 
• Python has prebuilt data science modules that both the novice and the veteran data scientist 
can utilize. 

These prebuilt modules are not only powerful, but also easy to pick up. By the end of the first few 
chapters, you will be very comfortable with these modules. Some of these modules are as follows: 

• Pandas (https://pandas.pydata.org) 
• sci-kit learn (https://scikit-learn.org) 
• seaborn (https://seaborn.pydata.org/tutorial/introduction) 
• numpy/scipy (https://numpy.org 
• requests (to mine data from the Web) 
• BeautifulSoup (for the Web-HTML parsing)
