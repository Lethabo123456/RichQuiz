4.1 
Introduction 
Machine learning is a subset of artificial intelligence that encompasses training algorithms to learn 
patterns and insights from data, rather than explicitly programming them to perform a specific task.In other words, machine learning algorithms use statistical techniques to identify patterns in data, 
which can then be used to make predictions or automated decisions. 
 
There are several types of machine learning, including supervised learning, which involves training 
algorithms on labelled data (data with known output) to make predictions about new, unlabelled data. 
Unsupervised learning involves finding patterns and relationships in data without any pre-existing 
labels, while reinforcement learning involves training algorithms based on the feedback they receive 
from their interactions with a situation or context (Chohan, 2019). 
 
This chapter focuses on machine learning as a practical part of data science. We will cover the 
following topics in this chapter: 
• Defining the different types of machine learning, along with examples of each kind 
• Areas in regression and classification 
• What is machine learning and how it is used in data science? 
• The differences between machine learning and statistical modelling and how machine 
learning is a broader category of the latter.
