• Are there any missing data points? Data isn't perfect. Sometimes we might be missing data 
because of human or mechanical error. When this happens, we, as data scientists, must make 
decisions about how to deal with these discrepancies. 
• Do we need to perform any transformations on the columns? Depending on what level/type 
of data each column is at, we might need to perform certain types of transformations. For 
example, generally speaking, for the sake of statistical modelling and machine learning, we 
would like each column to be numerical. Of course, we will use Python to make any and all 
transformations (Sinan, 2016).
