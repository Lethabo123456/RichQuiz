Many of these systems have two major weaknesses: redundant data and isolated data. 
 Redundant data:  
Because each department or area in an organization has its own files in a file processing 
system, the same fields are stored in multiple files. If a file processing system is used at a 
school, for example, the Student file and the Student Schedule file both might store the same 
students’ names and addresses. 
Duplicating data in this manner can increase the chance of errors. If a student changes his or 
her address, for example, the school must update the address in each file in which it appears. 
If the Address field is not changed in all the files where it is stored or is changed incorrectly in
