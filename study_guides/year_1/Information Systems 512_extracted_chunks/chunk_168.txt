FUNCTIONS OF DBMS 
 Data Dictionary 
A data dictionary, sometimes called a repository, contains data about each file in the 
database and each field in those files. A DBMS uses the data dictionary to perform 
validation checks to maintain the integrity of the data. When users enter data, the data 
dictionary verifies that the entered data matches the field’s data type. The data dictionary 
also can limit the type of data that can be entered, often allowing a user to select from a list.

for specific data from the database. Users can instruct the DBMS to return or store the
