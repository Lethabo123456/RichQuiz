 TYPES OF DATABASES 
Every database and DBMS is based on a specific data model. A data model consists of rules 
and standards that define how the database organizes data. A data model defines how users 
view the organization of the data. It does not define how the operating system actually 
arranges the data on the storage media. A database typically is based on one data model.
