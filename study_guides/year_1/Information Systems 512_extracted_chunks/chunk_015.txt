 Database  
A database is a collection of data organized in a manner that allows access, retrieval, and use 
of that data. Database software is an application that allows users to create, access, and 
manage a database. Using database software, you can add, change, and delete data in a 
database; sort and retrieve data from the database; and create forms and reports using the 
data in the database.  
With most personal computer database programs, a database consists of a collection of 
tables, organized in rows and columns. Each row, called a record, contains data about a given 
item in the database, which is often a person, product, object, or event. Each column, called 
a field, contains a specific category of data within a record.
