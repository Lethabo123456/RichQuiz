GLOSSARY OF TERMS 

logically equivalent expressions: expressions that have the same truth value 
no matter which propositional functions and domains are used 
loop: an edge of the form (a, a) 
matrix: a rectangular array of numbers 
partial ordering: a relation that is reflexive, antisymmetric, and transitive 
predicate: part of a sentence that attributes a property to the subject 
premise: a statement, in an argument, or argument form, other than the 
final one 
proof: a demonstration that a theorem is true 
proposition: a statement that is true or false 
propositional variable: a variable that represents a proposition 
¬p (negation of p): the proposition with truth value opposite to the truth 
value of p 
rule of inference: a valid argument form that can be used in the 
demonstration that arguments are valid 
set: a collection of distinct objects 
symmetric matrix: a matrix is symmetric if it equals its transpose 
tautology: a compound proposition that is always true 
theorem: a mathematical assertion that can be shown to be true 
truth table: a table displaying all possible truth values of propositions 
undirected graph: a set of vertices and a set of undirected edges each of 
which is associated with a set of one or two of these vertices 
universal set: the set containing all objects under consideration 
venn diagram: a graphical representation of a set or sets S = T (set equality): 
S and T have the same elements
