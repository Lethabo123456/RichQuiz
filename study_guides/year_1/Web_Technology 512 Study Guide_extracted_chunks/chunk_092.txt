evaluated to either true or false. While your condition is still true the loop will go 
round and round. When it is false, the loop will end. Take this code as an example: 
var counter = 1; 
var answer = 0; 
while (counter < 11)  
{ 
answer = answer + counter; 
counter++; 
} 
document.write("answer= " + answer); 
 
Here, we have two variables, one called counter and the other, like before, called 
answer. Inside of the round brackets of while, we have this: 
counter< 11 
 
This will be evaluated to true or false each time round the loop. It says, "while counter 
is less than 11 keeplooping".
