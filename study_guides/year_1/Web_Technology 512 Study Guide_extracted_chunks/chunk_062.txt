One way to control the flow of your code is with conditional logic. Conditional logic is 
all about what happens IF a condition is met or not met. For example, you may have an 
email text box on a form that you want your users to fill in. You don't want this text 
box to be empty when the user click the SUBMIT button. So you need a way to say "IF 
the email address is missing THEN do not send the 
form". You do this with IF Statement. 
 
3.4.1 IF Statements

your JavaScript code. An IF Statement will evaluate 
to either true or false. They look like this:

{  
 
//code to be executed comes here. 
}
