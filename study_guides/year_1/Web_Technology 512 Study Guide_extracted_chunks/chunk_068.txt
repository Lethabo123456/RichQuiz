3.4.3 IF … ELSE IF 
You can add another condition to test. This is done with ELSE IF. The syntax is this: 

if ( first_condition_to_test )  
{ 
//code to be executed if the first condition is true  
} 
else if ( second_condition_to_test )  
{ 
 /* code to be executed if the first condition is false 
 
and the second condition is true */ 
} 
 
Notice that else if is two words. If you type it as one word (elseif) then your code 
would not work. So it is just another IF statement with the word else in front of it. 
 
You can add as many else … if parts as you need: 
if ( first_condition_to_test )  
{ 
 //executes only if first condition is true. 
} 
else if ( second_condition_to_test )  
{ 
/*executes only if first condition is false and second 
condition is true.*/ 
} 
else if ( third_condition_to_test )  
{ 
/* executes only if first condition is false, second 
condition is true and third condition is true */. 
} 

Each condition you add will be evaluated to true or false. If JavaScript finds a true value 
then it will execute any code between the curly brackets that go with it. After that, it 
will exit the IF statements altogether. So if the second else if above is true then its code 
gets executed. The third else if will be skipped and your programme will continue on its 
way.
