7.1.1 The Validate Function 
The only thing our JavaScript will be doing is checking to see if users have filled out the 
form correctly. The strategy we will take is this: 
 
Set up four functions, one for each form element 
 
Return a value of true or false from these functions. A value of true will mean 
everything is OK, while a value of false will mean an error has been detected. 
 
The true or false values returned from the functions will be checked in an IF 
Statement. If all the values are true it means all form elements have been filled in 
correctly. So we can go ahead and send the form. If just one of them is false then the 
form will not be sent.
