6.1.5 The with Keyword 

 
91 
 
SIX | JAVASCRIPT OBJECTS 
The with keyword is used as a kind of shorthand for referencing an object's properties 
or methods. The object specified as an argument to with becomes the default object 
for the duration of the block that follows. The properties and methods for the object 
can be used without naming the object. 
 
Syntax: 
with (object) 
{ 
  //properties used without the object name and dot 
}
