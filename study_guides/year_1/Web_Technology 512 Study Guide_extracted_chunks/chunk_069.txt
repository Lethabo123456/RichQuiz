Each condition you add will be evaluated to true or false. If JavaScript finds a true value 
then it will execute any code between the curly brackets that go with it. After that, it 
will exit the IF statements altogether. So if the second else if above is true then its code 
gets executed. The third else if will be skipped and your programme will continue on its 
way.
