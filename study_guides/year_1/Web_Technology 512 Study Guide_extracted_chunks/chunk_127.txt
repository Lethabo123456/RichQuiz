5.2 JAVASCRIPT STRINGS - INDEXOF 
 
The indexOf method tells you if a string of text 
contains a particular character, the @ sign in an 
email address for example. It would not check 
every occurrence of the character, but just the 
first one. If the character cannot be found then 
IndexOf returns a value of -1 (minus 1). If the 
character is found then the value returned is the 
position in the string (6th character, for example).
