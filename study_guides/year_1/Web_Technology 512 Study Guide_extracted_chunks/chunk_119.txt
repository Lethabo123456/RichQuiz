The first line of code for the validate function is 
this: 
var textbox_value = document.getElementById("Name").value; 
 
We are setting up a variable called textbox_value here. Into this variable we want to 
store the value from the text box. This is done via the getElementById property of the 
document object (you will learn about getElementById in later section). Between its 
round brackets we have the ID from the text box. After a dot, we have value. This is 
enough to get the VALUE attribute from the text box.
