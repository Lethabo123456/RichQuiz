Previously, we got a reference to a text box by using getElementById. Another way to 
access form elements is to use the following syntax: 
document.form_name.element_name.element_value 
 
Our form was called frmOne, so we start with document.frmOne. The element name 
you are trying to access comes next. In the HTML, we gave our text box element the 
name email. If you want to get what was in the text box, you need the value attribute 
at the end. 
 
So we are getting the text value from the text box and storing it in a variable called 
email.
