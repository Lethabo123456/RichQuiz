You can use HTML tags with concatenation. For example, if you want to spread things 
over two lines, you can use the BR tag. Like this: 
document.write("SH="+window.screen.height+"<BR>"+"SW="+ 
window.screen.width); 
 
The BR tag is surrounded by quotation marks. You need the quote marks for any 
HTML that you insert using the write method.
