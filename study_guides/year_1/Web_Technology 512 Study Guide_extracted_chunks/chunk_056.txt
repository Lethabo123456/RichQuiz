You can use normal numbers with the mathematical operators. In the code below, we 
are adding up two numbers and storing the result in a variable: 
var result;  
result = 12 + 24; 
document.write( result ); 
 
JavaScript will add up the numbers on the right of the equal sign. When it has finished 
adding, it will store the result in the variable on the left of the equal sign.
