3.1.1 Variable Assignment  
When setting up a variable, we did this: 
var number1 = 42; 
 
But you do not have to store a value in the variable all on the same line. You can use 
two lines instead: 
var number1; 
number1 = 42; 
 
The first line here creates a variable called number1. But there is nothing stored in it. 
The second line is where we store something in the variable. Note that the var has now 
gone missing - you only need to use var once when you are setting up (declaring) your 
variables. 
 
You can also assign a different value to a variable. For example, you can do this: 
var number1; 
number1 = 42; 
number1 = 100;
