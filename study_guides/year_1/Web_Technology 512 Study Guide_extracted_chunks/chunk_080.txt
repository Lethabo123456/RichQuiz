Now the cookies_enabled variable has a NOT operator before it. By default, JavaScript 
will check for a true value. By placing a NOT operator before a Boolean value you are 
saying "If NOT true". If something is not true then it is false. In other words, if you 
want a quick way to check for a false value, type an exclamation mark before your 
Boolean variable. 
 
A popular use of the NOT operator is to toggle a Boolean to either true or false. It is 
done like this: 
bool_value = !bool_value;
