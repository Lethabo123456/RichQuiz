2.1 JAVASCRIPT SYNTAX 
A JavaScript consists of JavaScript statements that are placed within the <script>... 
</script> HTML tags in a web page. You can place the SCRIPT tags containing your 
JavaScript anywhere within you web page but it is preferred way to keep it within the 
HEAD tags. The SCRIPT tags inform the browser program to begin interpreting all the 
text between these tags as a script. The simple syntax of JavaScript will be as follows: 
 
JavaScript Syntax 
 
<script ...> 
  JavaScript code 
</script>
