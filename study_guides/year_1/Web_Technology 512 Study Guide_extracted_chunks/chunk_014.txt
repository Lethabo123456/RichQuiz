2.1 JAVASCRIPT SYNTAX 
A JavaScript consists of JavaScript statements that are placed within the <script>... 
</script> HTML tags in a web page. You can place the SCRIPT tags containing your 
JavaScript anywhere within you web page but it is preferred way to keep it within the 
HEAD tags. The SCRIPT tags inform the browser program to begin interpreting all the 
text between these tags as a script. The simple syntax of JavaScript will be as follows: 
 
JavaScript Syntax 
 
<script ...> 
  JavaScript code 
</script> 
 
The script tag takes two important attributes: 
 language: This attribute specifies what scripting language you are using. Typically, its 
value will be javascript. Although recent versions of HTML (and XHTML, its successor) have phased 
out the use of this attribute. 
 type: This attribute is what is now recommended to indicate the scripting 
language in use and its value should be set to "text/javascript". 
 
So your JavaScript segment will look like: 
<script language="javascript" type="text/javascript"> 
 
JavaScript code 
</script> 
 
OR 

<script language="javascript"> 
 
JavaScript code 
</script> 
 
OR 
<script type="text/javascript"> 
 
JavaScript code 
</script>
