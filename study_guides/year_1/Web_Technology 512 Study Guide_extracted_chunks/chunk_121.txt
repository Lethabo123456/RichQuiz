<P ID="message">First Name</P> 
 
The inner HTML is "First Name". This will be erased and replaced with the new text. 
The new text goes after an equal sign. For us, this is whatever is in the variable called 
error. 
 
The else statement sets the innerHTML back to "First Name". We do not really need 
this, but it is there for testing purposes.  
 
The return false line is also not needed in this simple piece of code. But in reality, you 
would add it if you were going to send your form data somewhere. Adding return 
false cancels the sending so that the user can try again.
