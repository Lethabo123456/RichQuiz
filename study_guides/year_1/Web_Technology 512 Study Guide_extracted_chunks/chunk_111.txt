This is the important line: 
var retVal = secondFunction(); 
 
We still have the function call. But this time it is on 
the right hand side of an equal sign. A single equal 
sign is the assignment operator, remember. So 
we're assigning a value to the variable on the left 
of the equal sign. The value we are assigning is 
whatever we get back from the function called 
secondFunction.So bear that in mind: if you want 
to return a value from a function, assign it to a variable on the left of an equal sign.

simple example, we are just displaying the value in an alert box.
