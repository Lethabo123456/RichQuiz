Figure 4.7 –Calling a function with multiple arguments 
We are passing over our two arguments with this: 
var retVal = secondFunction( cookiesEnabled, isOnline ); 
 
Whatever is in these two variables will be passed to the two variables in the 
secondFunction. 
In JavaScript, however, you do not need to pass over the same number of arguments. 
This, for example, is perfectly valid: 
var retVal = secondFunction( cookiesEnabled ); 
 
Here, we are only passing over one of the two values that secondFunction has set up. 
JavaScript, unlike other programming languages, would not give you any error 
messages if the number of arguments does not agree. You could even miss out both 
arguments between the round brackets and JavaScript won't complain. So this is OK 
as well (but fairly pointless): 
var retVal = secondFunction();
