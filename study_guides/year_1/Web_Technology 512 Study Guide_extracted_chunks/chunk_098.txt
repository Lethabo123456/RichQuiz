4.1 JAVASCRIPT ARRAYS 
 
A normal JavaScript variable such as var age = 18 holds a single piece of data. An array 
is a way to hold more than one piece of data under the same name. There are three 
ways to set up an array but the simplest (Literal) looks like this: 
var my_array = [10, "ten", true]; 
 
This sets up an array to hold three values all under 
the single variable
