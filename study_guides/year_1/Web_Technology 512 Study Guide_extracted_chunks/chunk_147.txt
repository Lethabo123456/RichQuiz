6.2.2 The Boolean Object 
The Boolean object represents two values either "true" or "false". 
 
Syntax: 
Creating a boolean object: 
var val = new Boolean(value); 
 
If value parameter is omitted or is 0, -0, null, false, NaN, undefined, or the empty 
string (""), the object has an initial value of false.
