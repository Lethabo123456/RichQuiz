6.2.3 The String Object 
The String object lets you work with a series of characters and wraps JavaScript’s 
string primitive data type with a number of helper methods.Because JavaScript 
automatically converts between string primitives and String objects, you can call any 
of the helper methods of the String object on a string primitive. 

Syntax: 
Creating a String object: 
var val = new String(string); 
 
The string parameter is series of characters that has been properly encoded.
