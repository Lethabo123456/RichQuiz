Reset buttons 
You can use a reset button to clear all entries in a form and allow users to reenter data. To 
create a reset button, you assign the value “reset” to the TYPE attribute of the INPUT tag. 
By default, the reset button has the label “Clear.” You can change this by using the 
VALUE attribute.
