4.3 COMMENTS 
In HTML a comment (or comments) is information a designer can add to the HTML 
source code for reference. Comments are not viewed by the user or displayed on the 
web browser, but only when viewing the HTML source code. HTML allows you to add 
comments within the code to help the reader better understand the code. To add a 
comment to the code for a page, use the following code:
