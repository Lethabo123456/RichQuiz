3.5 ADDING BODY TEXT 

You can add content to an HTML document by using the BODY tag (body). In the BODY tag 
you can include tags to add headings, paragraphs, lists, tables, and images to a Web page. 
For instance, to create a heading on a page, use the H1 tag (heading 1). This tag marks text 
that will appear as a heading.
