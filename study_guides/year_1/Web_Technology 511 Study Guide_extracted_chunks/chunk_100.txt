Browser support for audio formats 
 
Playing Web Audio 
The following is an HTML code for a web page on which you will be able to play 
audio files on the browser. 
 
 
The following is the desired output of the HTML code snippet above. 
 
 
HTML <audio> Autoplay 
To start an audio file automatically, use the autoplay attribute: 
 
HTML <audio> Autoplay muted 
Add muted after autoplay to let the audio file start playing automatically (but muted)
