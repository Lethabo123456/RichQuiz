INTRODUCTION 
You can explore the Web either by clicking hyperlinks or by using the address bar on 
your browser. You use the address bar for specifying the address of a Web page, 
which is called a Uniform Resource Locator, or URL. 
 
3.1 UNIFORM RESOURCE LOCATOR 
To identify a particular page or document on the Internet you need an Internet 
address called a Uniform Resource Locator, or URL. A URL consists of 
three major components that provide the necessary information to find a specific 
document. These components are separated by a forward slash (/). For example, the URL for PC 

Training and Business College Website might be as follows: 
http://www.pctbc.co.za where: 
 http:// is a protocol used. 
 www.pctbc.co.za/ is the host name and domain of the server. 
 site/…… is the directory path where the page is stored. The path might also include 
file names.
