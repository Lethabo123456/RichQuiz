2.4.2 Web Apps and Mobile apps 
 
A web app is an application stored on a web server that you access through a browser. Users 
typically interact with web apps directly at a website, sometimes referred to as the host. Web app 
hosts usually provide storage for users’ data and information on their servers known as cloud 
storage.
