There are different types of keyboards for Personal Computers, Handheld Computers and 
Computer appliances.   
  
 Enhanced Keyboard: This is a normal keyboard for personal computers having 12 functions 
keys on the top, 2 ctrl keys, 2 alt keys etc.  
 Cordless Keyboard: This is a battery-powered device that transmits data using wireless 
technology  
 Inbuilt Keyboard: This is a like enhanced keyboard but it is built in for Laptops, Notebooks 
etc  
  
 Portable Keyboard: This is a pocket sized portable keyboard, which can attach and remove 
from a handheld computer.
