Pointing device A device, such as a mouse or trackball that enables you to select objects on the

Programming software usually provides tools to assist a programmer in writing computer 
programs, and software using different programming languages in a more convenient way.  
  
System software helps run the computer hardware and computer system.  
  
Terminal A monitor and keyboard. Such terminals are known as dumb terminals because they 
have no processing power – they cannot act as stand-alone computers and they need the 
minicomputer connected to them at all times.
