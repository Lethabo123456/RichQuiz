 Examples of Operating Systems 
Laptops, tablets, and desktop computers all run operating systems that you've probably heard of. 
Some examples include versions of Microsoft Windows (like Windows 10, Windows 8, Windows 7, 
Windows Vista, and Windows XP), Apple's macOS (formerly OS X) Chrome OS, and flavors of the 
open source operating system Linux. 
Your smartphone runs an operating system too, probably either Apple's iOS or Google's Android. 
Both are household names but you may not have realized that they are the operating systems 
being utilized on those devices. 
Servers, like those that host the websites you visit or serve the videos you watch, typically run 
specialized operating systems, designed and optimized to run the special software required to 
make them do what they do. Some examples include Windows Server, Linux, and FreeBSD.
