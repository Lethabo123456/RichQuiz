Visitors to a static web page all see the same content, while with dynamic webpage, by contrast, 
visitors can customise some all of the viewed content such as desired stock quotes, weather for a 
region or availability of flight or bus tickets etc. 
 
A website is a collection of related webpages and associated items such as documents and pictures, 
stored on a web server. A web server is a computer that delivers requested webpages to your 
computer or mobile device. The same webserver can store multiple websites. A webpage has a 
unique address, called a web address or URL.
