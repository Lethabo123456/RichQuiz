Plots vs. Charts - we seem to use these terms interchangeably. We’ll say things like “a bubble chart is a particular kind 
of scatter plot”. The only real difference is that charts use some kind of symbol to represent the data. 
“A chart is a graphical representation of data, in which the data is represented by symbols, such as bars in a bar chart, 
lines in a line chart, or slices in a pie chart. A chart can represent tabular numeric data, functions or some kinds of 
qualitative structure and provides different info.”

of 100 coordinate pairs, but we’ll seed NumPy’s random number generator so that everyone receives the same
