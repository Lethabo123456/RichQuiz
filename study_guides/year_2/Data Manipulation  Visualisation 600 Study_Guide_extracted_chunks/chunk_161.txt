5. Whenever an input property changes, the function that the callback decorator wraps will get called 
automatically. Dash provides the function with the new value of the input property as an input argument 
and Dash updates the property of the output component with whatever was returned by the function. 
6. The component_id and component_property keywords inside Output and Input are optional 
(there are only two arguments for each of those objects). We included them here for clarity but we’ll 
omit them from here on out for brevity and readability.
