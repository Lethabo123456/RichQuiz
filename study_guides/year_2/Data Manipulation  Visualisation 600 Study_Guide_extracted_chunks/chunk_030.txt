1.3.1  Data Cleaning 
Data cleaning refers to identifying and addressing issues or inconsistencies in a dataset to prepare it for analysis. It 
involves various tasks to ensure the data is accurate, complete, and properly formatted. Some common data cleaning 
tasks using Pandas include handling missing data/values, removing duplicates and identifying outliers.  

1.3.2 Handling Missing Data 
None and NaN (Not a Number) represent missing or undefined values. NaN and None both have their place, and 
Pandas is built to handle the two of them nearly interchangeably, converting between them where appropriate. 

1.3.3 Detecting Null Values 
Null values can be detected using the isnull() method, which will return either True or False depending on whether it 
is invalid. We can also use the isnull() method to determine the total number of null values.  
 
1.4 Dropping Null Values: 
Null values in a DataFrame can be removed using the dropna() method.
