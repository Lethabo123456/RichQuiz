3.3 NumPy Array Attributes 
NumPy arrays possess several key attributes that offer insights into their characteristics. The shape attribute returns 
a tuple specifying the dimensions of the array, while ndim indicates the number of dimensions or axes. The size 
attribute provides the total number of elements in the array, and dtype reveals the data type of its elements. The 
itemsize attribute informs about the size, in bytes, of each element. The data attribute points to a buffer object 
containing the array's data in memory. Additionally, the flags attribute furnishes information on the memory layout, 
offering details such as contiguity and ownership. These attributes empower data scientists and practitioners to 
comprehend and manipulate NumPy arrays efficiently, aiding in diverse applications ranging from scientific
