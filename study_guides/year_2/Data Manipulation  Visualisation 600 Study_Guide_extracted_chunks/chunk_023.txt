Chapter 1: Introduction to Pandas for Data Manipulation 
 
Introduction  
Pandas is a powerful and widely used open-source data manipulation and analysis library for Python. It provides easy-
to-use data structures, such as Series and DataFrame, and various functions for efficiently manipulating large datasets.  

1.1 Series: 
A series is a one-dimensional labelled array capable of holding any data type. "Labelled" means that each element in 
the series has an associated label or index.  

1.1.1 Creating a Series (default index) 
By default, a series is labelled using the index position of the values. The index position starts from 0 until the length 
(number of values in the series) - 1.  
• Firstly, import the Pandas library using import pandas as pd as shown in Example 1.1 image below. 
• We then create a list called data containing some numeric values. 
• Using the pd.Series() constructor, we create a series named my_series from the data list. 
• Finally, we print the series, displaying default index values (0, 1, 2, ...) and the corresponding data. 
• The dtype: int64 indicates that the data type of the Series is a 64-bit integer. 

1.1.2 Creating a Series (custom index)
 
A custom index can be created by using a list to store the custom index or by creating and converting a dictionary to 
a series. 

• Once again, we import the pandas library and create a list called data as shown in example 1.2 image below. 
• This time, instead of using the default index, we will create a list (labels) to store our custom index. 
• When using the pd.Series() constructor, we pass the data and labels list. 
• Finally, we print the series, which will be displayed along with the custom index values (a, b, c, ...) and the 
corresponding data.
