For starters, let’s create basic heatmaps for each dataset (these are, heat2.py and heat3.py) and 
accept plotly’s default parameters. Note that temperatures are given in degrees Celsius. 
heat1.py creates a heatmap from SantaBarbaraCA.csv: 
import plotly.offline as pyo 
 
import plotly.graph_objs as go 
import pandas as pd 
 
df = pd.read_csv('../data/2010SantaBarbaraCA.csv') 
 
data = [go.Heatmap( 
x=df['DAY'], 
y=df['LST_TIME'], 
z=df['T_HR_AVG'].values.tolist(), 
colorscale='Jet' 
)] 
layout = go.Layout( 
title='Hourly Temperatures, June 1-7, 2010 in<br>\ 
Santa Barbara, CA USA' 
) 
fig = go.Figure(data=data, layout=layout) 
pyo.plot(fig, filename='Santa_Barbara.html')
