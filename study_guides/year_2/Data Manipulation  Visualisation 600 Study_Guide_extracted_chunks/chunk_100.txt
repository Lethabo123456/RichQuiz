 6.1 Overview of Plotly in Python 
 Plotly is a Python graphing library that allows you to create interactive and visually appealing plots. It supports a 
wide range of chart types, including scatter plots, line charts, bar charts, pie charts, and more. Plotly is known for its 
ability to generate interactive plots, which means that users can zoom, pan, and hover over data points to get more 
information. 
Key Features 
● Interactive Visualizations: Plotly produces interactive visualizations that can be embedded in web 
applications or Jupyter notebooks. 
● Wide Range of Chart Types: It provides support for various chart types, making it versatile for different data 
visualization needs.
