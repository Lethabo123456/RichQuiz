1.2 DataFrame 
A DataFrame is a two-dimensional, tabular data structure. "Two-dimensional" refers to a structure with two axes: 
rows and columns. Rows represent the observations or records in the dataset. Columns represent the variables or 
features associated with each observation. "Tabular" implies that the data is organised in a table or grid-like format.

1.2.2 Accessing Columns in a DataFrame 
We can access the columns in a DataFrame using the column's name or the loc and iloc indexers. The loc indexer is 
primarily label-based and is used for selecting data by row labels and column names. The iloc indexer is integer-
location-based and is used for selecting data by integer indices.
