• Type I Error: A type I error occurs if we reject the null hypothesis when it is true. This 
is also known as a false positive. The type I error rate is equal to the significance level 
α, which means that if we set a higher confidence level, for example, a significance 
level of 99%, our α is .01, and therefore our false positive rate is 1%. 
• Type II Error: A type II error occurs if we fail to reject the null hypothesis when it is 
false. This is also known as a false negative. The higher we set our confidence level, 
the more likely we are to see a type II error.
