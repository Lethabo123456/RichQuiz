Practical Example: Movie Recommendation Engine 
• Imagine having a user preference profile (vector) and a database of 10,000 movies, 
each rated across different genres (comedy, romance, action). 
• The user's preferences can be represented as a vector (or a 3x1 matrix), and the movie 
database as a 3x10,000 matrix. 

Matrix Multiplication in Action 
19. Transpose the user preference vector to match dimensions for multiplication. 
20. Multiply the transposed user preference matrix with the movie matrix. 
21. The resulting matrix (vector) contains a score for each movie, indicating how well it 
matches the user's preferences. 
Implementing in Python with NumPy 
• NumPy is a powerful library in Python for numerical computing, particularly efficient 
for operations with arrays and matrices. 
• The numpy.dot () function can perform matrix multiplication. 
• Example: 
limport numpy as np  
# User preferences  
user_pref = np.array([5, 1, 3])  
# Movie ratings matrix  
movies = np.random.randint(5, size=(3, 10000)) + 1  
# Matrix multiplication  
recommendations = np.dot(user_pref, movies)  
# Display results  
print(recommendations)  
  
Performance 
• This approach is highly efficient, allowing computation over millions of movies in 
seconds.
