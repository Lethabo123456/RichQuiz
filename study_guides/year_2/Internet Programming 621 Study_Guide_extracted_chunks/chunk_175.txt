Finally, you can also access global variables using the $GLOBALS array. This array is a special type of 
variable called a superglobal , which means you can access it from anywhere without using the 
global statement. It contains a list of all global variables, with the variable names stored in its keys 
and the variables’ values stored in its values. Here is an example that uses $GLOBALS :  
  
$myGlobal = “Hello there!”;  
  
function hello() { echo 
$GLOBALS[“myGlobal”] . “ < br/ > ”;  
}  
  
hello(); // Displays “Hello there!”
