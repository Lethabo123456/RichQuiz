2.1 Variables  
A variable is simply a container, so to speak, and it holds a certain value. Variables get their name 
from the fact that the quantities that they contain can change their values throughout the execution 
of the script. It is this ability to contain changing values that makes variables so useful. For example, 
consider the following simple PHP script:  
  
echo 2 + 2;
