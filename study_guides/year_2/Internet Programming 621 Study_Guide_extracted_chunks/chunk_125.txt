You might want to use count() to retrieve the last element of an indexed array:  
  
$authors = array( “Steinbeck”, “Kafka”, “Tolkien”, “Dickens” );  
$lastIndex = count( $authors ) - 1; echo 
$authors[$lastIndex]; // Displays “Dickens”  
  
This works, but be careful. Just because an indexed array has, say, four elements, it does not 
necessarily mean that the last element has an index of 3! Consider the following (somewhat 
contrived) example:
