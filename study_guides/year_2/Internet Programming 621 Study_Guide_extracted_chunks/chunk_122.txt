$authors = array( “Steinbeck”, “Kafka”, “Tolkien”, “Dickens” );  
$authorsSlice = array_slice( $authors, 1, 2 ); // 
Displays “Array ( [0] = > Kafka [1] = > Tolkien )” 
print_r( $authorsSlice );  
  
This example extracts the second and third elements from the $authors array and stores the 
resulting array in a new variable, $authorsSlice . The code then uses print_r() to display the slice. 
Note that array_slice() does no t preserve the keys of the original elements, but instead re-indexes 
the elements in the new array, starting from zero. So whereas “ Kafka ” has an index of 1 in the 
$authors array, it has an index of 0 in the $authorsSlice array.
