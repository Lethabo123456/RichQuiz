6.10 Working With Global Variables  
Although the concept of variable scope is extremely useful, occasionally you do actually want to 
create a variable that can be accessed anywhere in your script, whether inside or outside a function. 
Such a variable is called a global variable .  
  
PHP supports global variables, but if you are used to other programming languages you will find PHP 
handles globals slightly differently. In PHP, all variables created outside a function are, in a sense, 
global in that they can be accessed by any other code in the script that is not inside a function. To 
use such a variable inside a function, write the word global followed by the variable name inside the 
func
