Earlier you learned that array_slice() does not preserve the indices of elements taken from an 
indexed array. If you want to preserve the indices, you can pass a fourth argument, true, to 
array_slice() :  
  
$authors = array( “Steinbeck”, “Kafka”, “Tolkien”, “Dickens” );  
// Displays “Array ( [0] = > Tolkien [1] = > Dickens )”; 
print_r( array_slice( $authors, 2, 2 ) );  
// Displays “Array ( [2] = > Tolkien [3] = > Dickens )”; 
print_r( array_slice( $authors, 2, 2, true ) );
