In programming - speak, a string is simply a sequence of characters. For instance, the values “hello” , 
“how are you?” , “123”, and “!@#$%” are all valid string values.  
  
In this unit, we look at the basics of strings in PHP — how to create string values and variables, and 
how to access characters within strings. We then explore PHP ’s string functions. We do no t aim to 
cover every single string function in PHP; the subject could fill a whole book on its own. Instead, you 
get to learn about the most useful (and commonly used) functions that you are likely to need in 
everyday situations.
