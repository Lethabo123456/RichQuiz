Testing PHP  
Now that you know Apache is working correctly, it is time to make sure PHP is installed and working. 
This is where you get to write your very first PHP script!  
  
Open your text editor again, and create a new file with the following contents:  
  
  
  
< ?php phpinfo();  
? >  
  
  
  
Save this file as testing.php in the same folder as your testing.html file — that is to say, the 
document root folder. Now type the following into your Web browser ’s address bar (adjusting the 
HTTP port number if necessary):  
  
http://localhost/testing.php
