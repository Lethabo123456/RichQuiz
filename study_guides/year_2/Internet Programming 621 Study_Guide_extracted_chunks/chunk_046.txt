2.6 Testing Variable Types  
You can determine the type of a variable at any time by using PHP’s gettype() function. To use 
gettype(), pass in the variable whose type you want to test into the gettype() function by typing the 
name of the variable within the parentheses of the gettype() function. The function then returns the 
variable’s type as a string.
