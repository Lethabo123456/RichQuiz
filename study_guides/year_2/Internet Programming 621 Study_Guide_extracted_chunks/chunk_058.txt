2.12 String Operators  
There is really only one string operator, and that is the concatenation operator , . (dot). This operator 
simply takes two string values, and joins the right-hand string onto the left-hand one to make a longer 
string. For example:  
  
  
  
  
  
echo “Shaken, “ . “not stirred”; // Displays “ Shaken, not stirred ”
