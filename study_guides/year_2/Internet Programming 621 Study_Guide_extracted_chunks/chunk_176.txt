The hello() function accesses the contents of the $myGlobal variable via the $GLOBALS array. Notice 
that the function does not have to declare the $myGlobal variable as global in order to access its 
value.  
PHP makes other superglobal variables available to you as well. Be careful with global variables. If 
you modify the value of a global variable in many different places within your application, it can 
make it hard to debug your code when something goes wrong. Generally speaking, you should avoid 
using global variables unless it is strictly necessary.
