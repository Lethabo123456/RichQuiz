Virtual Private Network (VPN) 
The use of a virtual private network is another means used to secure the transmission of 
communications. A virtual private network (VPN) is a private network that uses a public 
network (usually the Internet) to connect multiple remote locations. A VPN provides network 
connectivity over a potentially long physical distance and thus can be considered a form of 
wide area network. VPNs support secure, encrypted connections between a company’s
