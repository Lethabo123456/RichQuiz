Workgroup Operating Systems 
To keep pace with user demands, the technology of the future must support a world in which 
network usage, data-storage requirements and data-processing speeds increase at a dramatic 
rate. Powerful and sophisticated OSs are needed to run the servers that meet these business 
needs for workgroups. 
 
Windows Server

corporate web applications. For example, Microsoft Windows Server can be used to coordinate 
large data centres. It delivers benefits such as a powerful web server management system, 
virtualization tools that allow various operating systems to run on a single server, advanced 
security features and robust administrative support. Windows Home Server allows individuals
