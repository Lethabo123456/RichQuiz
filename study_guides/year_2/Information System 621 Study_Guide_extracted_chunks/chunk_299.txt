Mac OS X Server 
 
The Mac OS X Server is the first modern server OS from Apple Computer and is based on the 
UNIX OS. The most recent version is macOS Server 5. It includes support for 64-bit 
processing, along with several server functions and features that allow the easy management of 
network and Internet services such as email, website hosting, calendar management and 
sharing, wikis and podcasting.
