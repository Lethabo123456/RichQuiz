A web browser plug-in is an external program that is executed by a web browser when it is 
needed. For example, if you are working with a web page and encounter an Adobe pdf file, the 
web browser will typically run the external Adobe pdf reader program or plug-in to allow you 
to open the file. Microsoft Internet Explorer and Google Chrome are examples of web browsers 
for PCs. Safari is a popular web browser from Apple for their Macintosh computer, and Mozilla 
Firefox is a web browser available in numerous languages that can be used on PCs, computers 
with the Linux operating system and Apple Mac computers.
