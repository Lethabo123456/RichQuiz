Another approach to obtaining a customized software package is to use an application service 
provider. An application service provider (ASP) is a company that can provide the software, 
support and computer hardware on which to run the software from the user’s facilities over a 
network. Some vendors refer to the service as on-demand software. 
 
Today, many companies are running software on the web. This approach is called Software as 
a Service (SaaS), which allows businesses to subscribe to web-delivered application software.
