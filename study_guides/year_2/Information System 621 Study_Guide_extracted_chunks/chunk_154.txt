consist of millions of switches that are sensitive to changes in electrical current.  
RAM comes in many varieties: static random access memory (SRAM) is byte-addressable 
storage used for high-speed registers and caches; dynamic random access memory (DRAM) is 
byte-addressable storage used for the main memory in a computer; and double data rate 
synchronous dynamic random access memory (DDR SDRAM) is an improved form of DRAM 
that effectively doubles the rate at which data can be moved in and out of main memory. Other 
forms of RAM memory include DDR2 SDRAM and DDR3 SDRAM.
