Network and Internet Utilities 
 
A broad range of network- and systems-management utility software is available to monitor 
hardware and network performance and trigger an alert when a server is crashing or a network 
problem occurs. IBM’s Tivoli Netcool and Hewlett-Packard’s Automated Network 
Management Suite can be used to solve computer-network problems and help save money. In 
one survey, about 60 per cent of responding organizations used monitoring software to 
determine if their Internet sites and Internet applications were running as expected.
