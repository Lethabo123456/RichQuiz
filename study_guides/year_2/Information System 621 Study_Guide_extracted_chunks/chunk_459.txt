In client/server architecture, multiple computer platforms are dedicated to special functions 
such as database management, printing, communications and program execution. These 
platforms are called servers. Each server is accessible by all computers on the network. 
Servers can be computers of all sizes; they store both application programs and data 
files and are equipped with operating system software to manage the activities of the 
network. The server distributes programs and data to the other computers client/server 
(clients) on the network as they request them. An application server holds the programs 
and data files for a particular application, such as an inventory database. The client or the
