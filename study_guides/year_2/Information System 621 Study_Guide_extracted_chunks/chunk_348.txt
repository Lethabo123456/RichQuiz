translates into several instructions in machine language. A special software program called a 
compiler converts the programmer’s source code into the machine- language instructions, 
which consist of binary digits, as shown in Figure 4.4 (overleaf). A compiler creates a twostage 
process for program execution. First, the compiler translates the program into a machine
