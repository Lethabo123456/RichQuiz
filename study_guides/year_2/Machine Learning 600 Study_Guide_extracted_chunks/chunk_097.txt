Activation Function. The activation function is the processing that happens after the input is 
passed into the neuron. The result of this function determines whether the value is passed to 
the output axon and onto the next neuron in the network. Commonly, the sigmoid function 
(see Figure 5.10) and the hyperbolic tangent are used as activation functions to calculate the 
output. The Sigmoid function outputs only one of two values: 0 and 1.
