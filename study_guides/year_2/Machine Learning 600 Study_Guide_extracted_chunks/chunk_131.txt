 
The MinMax scaler is the core algorithm used to change the scale of values. For each 
value in the feature, the transformation goes through the following steps: 
1. The value is subtracted from the minimum value of the feature in the dataset. 
2. The resulting value is divided by the range—namely, the difference between the 
maximum and minimum value of the feature in the dataset. 
 
The MinMax scaler doesn’t alter the distribution of values and maintains the relative 
distance between values. 

