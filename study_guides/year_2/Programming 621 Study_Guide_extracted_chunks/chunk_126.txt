Function Overloading 
In a C++ program, several functions can have the same name. This is called 
function overloading, or overloading a function name. 
Two functions are said to have different formal parameter lists if both functions 
have  
 A different number of formal parameters or  
 The same number of formal parameters and the data types of the formal 
parameters, in the order listed, differ in at least one position.
