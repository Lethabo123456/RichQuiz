The statement

 stores the address of x in p. However, no new memory is allocated. On the other 
hand, consider the following statement: 
 
 p = new int; 
 
This statement creates a variable during program execution somewhere in memory 
and stores the address of the allocated memory in p. The allocated memory is 
accessed via pointer dereferencing—namely, *p.
