Moreover, the statement p = p + 2; increments the value of p (an int pointer) by 8 
bytes. Thus, when an integer is added to a pointer variable, the value of the pointer 
variable is incremented by the integer times the size of the data type or structure to 
which the pointer is pointing. Similarly, when an integer is subtracted from a pointer 
variable, the value of the pointer variable is decremented by the integer times the size 
of the data type or structure to which the pointer is pointing.
