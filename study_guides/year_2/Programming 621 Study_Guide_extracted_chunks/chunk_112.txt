Because C++ does not provide every function that you will ever need and designers 
cannot possibly know a user’s specific needs, you must learn to write your own 
functions. 
User-defined functions in C++ are classified into two categories:  
 Value-returning functions—functions that have a return type. These functions 
return a value of a specific data type using the return statement, which we will 
explain shortly. Note that the function main has used a return statement to 
return the value 0 in every program we’ve seen so far.  
 Void functions—functions that do not have a return type. These functions do 
not use a return statement to return a value.
