You can see that the data is in a table format. The table has 30 entries, and every 
entry is an integer. Because the table entries are all of the same type, you can declare 
a one-dimensional array of 30 components of type int. The first five components of the 
one-dimensional array can store the data of the first row of the table, the next five 
components of the one-dimensional array can store the data of the second row of the 
table, and so on. In other words, you can simulate the data given in a table format in 
a one-dimensional array. 
 
Two-dimensional array: A collection of a fixed number of components arranged in 
rows and columns (that is, in two dimensions), wherein all components are of the same 
type.
