virtual functions. The binding of virtual functions occurs at program execution time, not 
at compile time. This kind of binding is called run-time binding, late binding, or 
dynamic binding.  
 
More formally, in run-time binding he compiler does not generate the code to call a 
specific function. Instead, it generates enough information to enable the run-time 
system to generate the specific code for the appropriate function call. Run-time binding 
is also known as dynamic binding.
