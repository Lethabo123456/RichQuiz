In the case of a one-dimensional array, when declaring it as a formal parameter, we 
usually omit the size of the array.  
Because C++ stores two-dimensional arrays in row order form, to compute the 
address of a component correctly, the compiler must know where one row ends and 
the next row begins. Thus, when declaring a twodimensional array as a formal 
parameter, you can omit the size of the first dimension, but not the second; that is, you 
must specify the number of columns.
