This is typically true for any class. That is, every class has member functions that only 
access but do not modify the member variables, called accessor functions, and 
member functions that modify the member variables, called mutator functions. 
 
Accessor function: A member function of a class that only accesses (that is, does 
not modify) the value(s) of the member variable(s). 
Mutator function: A member function of a class that modifies the value(s) of the 
member variable(s).
