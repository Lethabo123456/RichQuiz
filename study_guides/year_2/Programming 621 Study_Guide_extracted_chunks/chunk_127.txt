Function overloading: Creating several functions with the same name. The 
signature of a function consists of the function name and its formal parameter list. 
Two functions have different signatures if they have either different names or 
different formal parameter lists. (Note that the signature of a function does not 
include the return type of the function.) If a function’s name is overloaded, then
