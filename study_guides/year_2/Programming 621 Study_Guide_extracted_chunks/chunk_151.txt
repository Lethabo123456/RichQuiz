To initialize a two-dimensional array when it is declared:  
     1. The elements of each row are all enclosed within one set of curly braces and  
separated by commas.  
    2. The set of all rows is enclosed within curly braces.  
    3. For number arrays, if all components of a row are not specified, the unspecified 
components are initialized to 0. In this case, at least one of the values must be given 
to initialize all the components of a row.
