5.3 POINTERS 
The values belonging to pointer data types are the memory addresses of your 
computer. As in many other languages, there is no name associated with the pointer 
data type in C11. Because the domain—that is, the set of values of a pointer data 
type—is the addresses (locations) in memory, a pointer variable is a variable whose 
content is an address, that is, a memory location and the pointer variable is said to 
point to that memory location.
