Value Parameters 
When a function is called, for a value parameter, the value of the actual parameter is 
copied into the corresponding formal parameter. Therefore, if the formal parameter is 
a value parameter, then after copying the value of the actual parameter, there is no 
connection between the formal parameter and actual parameter; that is, the formal 
parameter is a separate variable with its own copy of the data. Therefore, during 
program execution, the formal parameter manipulates the data stored in its own 
memory space.
