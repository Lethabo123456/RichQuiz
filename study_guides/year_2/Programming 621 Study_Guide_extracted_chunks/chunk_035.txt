2. An algorithm is a step-by-step problem-solving process in which a solution is 
arrived at in a finite amount of time. 
3. The problem-solving process has three steps: analyze the problem and design 
an algorithm, implement the algorithm in a programming language, and 
maintain the program. 
4. In structured design, a problem is divided into smaller subproblems. Each 
subproblem is solved, and the solutions to all of the subproblems are then 
combined to solve the problem. 
5. Linker links the object code with other programs provided by the integrated 
development environment (IDE) and used in the program to produce 
executable code.
