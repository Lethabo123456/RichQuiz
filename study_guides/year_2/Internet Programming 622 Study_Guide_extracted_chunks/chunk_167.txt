4.16 Deleting Tables From Databases Using The DROP TABLE Statement   
To delete a table entirely, use the DROP TABLE statement. Similarly, you can delete an entire 
database with DROP DATABASE . First, here is how to use DROP TABLE:   
   
mysql > SHOW TABLES;   
+----------------------+   
| Tables_in_mydatabase |   
+----------------------+   
| fruit |   
+----------------------+   
1 row in set (0.00 sec)   
   
mysql > DROP TABLE fruit;
