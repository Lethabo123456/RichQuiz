A reset button — This type of button resets all form fields back to their initial values (often 
empty). The value attribute contains the button label text:   
   
               <label for=”resetButton”>A reset button</label>   
               <input type=”reset” name=”resetButton” id=”resetButton”  value=”Reset Form” />   
   
• 
A file select field — This allows the users to choose a file on their hard drive for uploading to 
the server. The value attribute is usually ignored by the browser:   
   
               <label for=”fileSelectField”>A file select field</label>   
               <input type=”file” name=”fileSelectField” id=”fileSelectField” value=”” />   
   
•
