4.1 Databease Architecture   
Before you get going, you need to settle on a particular database with which to experiment, and that 
means first deciding on the type of database architecture you are going to use. Broadly speaking, you 
have two main options: embedded and client-server. Let us take a brief look at both.   
   
4.2 Embedded Databases   
An embedded database engine, as its name implies, sits inside the application that uses it (PHP in 
this case). Therefore it always runs — and stores its data — on the same machine as the host 
application.
