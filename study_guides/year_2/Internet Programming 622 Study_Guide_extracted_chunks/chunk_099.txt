The terms “ directory ” and “ folder ” are used interchangeably in this guide; they mean exactly the 
same thing.   
   
A file is nothing more than an ordered sequence of bytes stored on a hard disk or other storage 
media.   
A directory is a special type of file that holds the names of the files and directories inside the folder 
(sometimes denoted as subdirectories or subfolders ) and pointers to their storage areas on the 
media.   
3.2 Getting Information On Files   
PHP provides some functions that enable you to access useful file information. For example, you can 
use file_exists() to discover whether a file exists before attempting to open it:   
   
file_exists( “/home/chris/myfile.txt” )
