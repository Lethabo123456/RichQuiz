You can limit the number of characters written by specifying an integer as a third argument. The 
function stops writing after that many characters (or when it reaches the end of the string, 
whichever occurs first). For example, the following code writes the first four characters of “ 
abcdefghij ” (that is, “ abcd “ ) to the file:   
   
fwrite( $handle, “abcdefghij”, 4 );
