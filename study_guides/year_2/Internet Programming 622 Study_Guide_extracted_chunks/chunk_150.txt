4.7 Understanding Relational Databases   
   
In simple terms, a relational database is any database system that allows data to be associated and 
grouped by common attributes. For example, a bunch of payroll records might be grouped by 
employee, by department, or by date. Typically, a relational database arranges data into tables, 
where each table is divided into rows and columns of data.   
In database parlance, each row in a table represents a data record:  a set of intrinsically connected 
pieces of data, such as information relating to a particular person. Likewise, each column represents 
a field : a specific type of data that has the same significance for each record in the table, such as “ 
first name ” or “ age. ”
