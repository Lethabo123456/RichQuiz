is_file() — Returns true if the given filename refers to a regular file   
   
Here is a simple example that determines if a file called myfile is a file or a directory:   
   
$filename = “myfile”; if ( is_dir( 
$filename ) ) {            echo “$filename 
is a directory.”; } elseif ( is_file( 
$filename ) ) {           echo “$filename 
is a file.”;   
} else {   
         echo “$filename is neither a directory nor a file.”;   
}
