The readdir() function expects a directory handle for an opened directory, and returns the filename 
of the next entry in the directory:   
   
$filename = readdir( $handle );   
   
Each directory contains a list of entries for each of the files and subdirectories inside it, as well as 
entries for . (representing the directory) and .. (the parent of the directory). PHP maintains an 
internal pointer referring to the next entry in the list, just as a file pointer points to the position in a 
file where the next file operation should occur.
