dirname() — Returns the directory portion of a path. The dirname() function returns the 
directory part of a given path. It complements the basename() function, which returns the 
filename portion of a given path, For example:    
   
$path = “/home/james/docs/index.html”;    
$directoryPath = dirname( $path );   
 $filename = basename( $path );    
   
After running this code, $directoryPath contains “ /home/james/docs ”, and $filename holds 
“ index.html ”.
