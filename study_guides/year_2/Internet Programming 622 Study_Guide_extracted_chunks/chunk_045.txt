The post method sends the data within the HTTP headers of the request that is sent to the server, 
rather than embedding the data in the URL. This allows a lot more data to be sent. If the users try to 
refresh the page after sending a form via the post method, their browser usually pops up a dialog 
box asking them if they want to resend their form data.
