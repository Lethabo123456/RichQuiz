The example below uses the same code used to illustrate cookies which is now being used to 
illustrate sessions. Once the session is started, the $bg and $fg variables are created, and all the 
script has to do is use them.

session_start() ;   
$backgroundName = $_SESSION['bg'] ;   
$foregroundName = $_SESSION['fg'] ;   
?>
