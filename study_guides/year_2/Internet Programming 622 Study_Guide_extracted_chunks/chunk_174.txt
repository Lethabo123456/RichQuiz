Now you can capture any error that might occur when connecting to the database by using a try ... 
catch code block. If you were writing a sophisticated application, you wouldd probably log the error 
message to a file, and possibly send an email to the Webmaster informing him of the details of the 
error. For the sake of these examples, though, you will just display the error message in the Web 
page:   
   
try {   
$conn = new PDO( $dsn, $username, $password );   
$conn- > setAttribute( PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION );   
} catch ( PDOException $e ) {   
echo “Connection failed: “ . $e- > getMessage();   
}
