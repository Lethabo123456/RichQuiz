PDO (PHP Data Objects) — This is an object-oriented extension that sits between the MySQL  
server and the PHP engine. It gives you a nice, simple, clean set of classes and methods that 
you can use to work with MySQL databases. Furthermore, you can use the same extension 
to talk to lots of other database systems, meaning you only have to learn one set of classes 
and methods in order to create applications that can work across MySQL, PostgreSQL, 
Oracle, and so on
