The ftell() function takes a file handle and returns the current offset (in characters) of the 
corresponding file pointer from the start of the file. For example:   
   
$offset = ftell( $handle );   
   
As you saw earlier, the fpassthru() function outputs file data from the current file position onward. If 
you have already read data from an open file but want to output the file’s entire contents, call 
rewind() first.
