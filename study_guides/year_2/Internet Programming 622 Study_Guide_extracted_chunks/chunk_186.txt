1. Download the latest version of WampServer from http://www.wampserver.com/en/. At the 
time of the writing of this guide, the latest version was PHP 5.2.6; however, by the time you 
read this it is likely that a PHP 5.3 version or higher is available.   
2. Open the WampServer .exe file that you downloaded, and follow the instructions on the 
screen to install the application.
