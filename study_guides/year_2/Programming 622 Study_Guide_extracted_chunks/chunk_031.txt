part of the main program; others are used to implement various operations on objects. Clearly, functions 
interact with each other, taking advantage of each other’s capabilities. To use a function, the user needs 
to know only how to use the function and what the function does. The user should not be concerned with 
the details of the function, that is, how the function is written. Let us illustrate this with the help of the 
following example.
