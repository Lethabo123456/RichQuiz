7.3.5  Hashing: Implementation Using Quadratic Probing  
  
Better behaviour is usually obtained with quadratic probing, where the secondary hash function depends 
on the re-hash index:   
  
address = h(key) + c i2   
  
on the tth re-hash. (A more complex function of i may also be used.) Since keys which are mapped to the 
same value by the primary hash function follow the same sequence of addresses, quadratic probing shows 
secondary clustering. However, secondary clustering is not nearly as severe as the clustering shown by 
linear probes.
