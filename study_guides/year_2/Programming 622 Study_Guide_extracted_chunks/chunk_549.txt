(h(X) + i * c) % HTSize  
  
If c = 2 and h(X) = 2k, that is, h(X) is even, only the even-numbered array positions are visited. Similarly, if 
c = 2 and h(X) = 2k + 1, that is, h(X) is odd, only the odd-numbered array positions are visited. To visit all 
the array positions, the constant c must be relatively prime to HTSize.

7.3.3.2 Random Probing  
  
This method uses a random number generator to find the next available slot. The ith slot in the probe 
sequence is  
(h(X) + ri) % HTSize  
  
where ri is the ith value in a random permutation of the numbers 1 to HTSize – 1. All insertions and 
searches use the same sequence of random numbers.
