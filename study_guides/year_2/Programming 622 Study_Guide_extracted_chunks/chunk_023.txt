Without software a computer is of no use. It is the software that enables you to do things that were, 
perhaps, fiction a few years ago. However, software is not created overnight. From the time a software 
program is conceived until it is delivered, it goes through several phases. There is a branch of computer 
science, called software engineering, which specializes in this area. Most colleges and universities offer a 
course in software engineering. This book is not concerned with the teaching of software engineering 
principles. However, this chapter briefly describes some of the basic software engineering principles that 
can simplify program design.
