When a program is considered too expensive to maintain, the developer might decide to retire the 
program and no new version of the program will be released.  
  
The software development phase is the first and perhaps most important phase of the software life cycle. 
A program that is well developed will be easy and less expensive to maintain. The next section describes 
this phase.  
  
 
1.2  
Software Development Phase  
  
Software engineers typically break the software development process into the following four phases:  
  
Analysis  
Design  
Implementation  
Testing and debugging  
  
The next few sections describe these four phases in some detail.
