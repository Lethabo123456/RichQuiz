A data correction involves re-entering data that was not typed or scanned properly. It is not 
enough simply to reject invalid data. The system should also provide error messages that alert 
those responsible for editing the data. Error messages must specify the problem so proper 
corrections can be made. For example, a scanned barcode must match a code in a master table 
of valid codes. If the code is misread or does not exist in the table, the shop assistant should be 
given an instruction to rescan the item or type the information manually.
