Data mapping is the examination of each data item required for the new ERP system and 
determining where that data item will come from. While most of the data for the new system 
will come from the files of existing legacy systems, some data items may need to be pulled 
from manual systems or may even need to be created for the new system. Data clean-up is 
required because the legacy systems are likely to contain data that is inaccurate, incomplete or 
inconsistent. For example, the same customer may be listed multiple times in existing customer 
files with varying billing addresses, or products may appear in the existing inventory files that 
have not been produced for years. Data loading can be performed either by using data 
conversion software that reads the old data and converts it into a format for loading into the 
database or by end-users entering data via the input screens of the new system.
