Unit testing is accomplished by developing test data that will force the computer to execute 
every statement in the program. In addition, each program is tested with abnormal data to 
determine how it will handle problems.  
  
Finally, acceptance testing makes sure that the new or modified system is operating as intended. 
Run times, the amount of memory required, disc access methods and more can be tested during 
this phase. Acceptance testing ensures that all performance objectives defined for the system 
or application are satisfied. Involving users in acceptance testing can help them understand and 
effectively interact with the new system. Acceptance testing is the final check of the system 
before start-up.
