Several forms of testing should be used, including testing each program (unit testing), testing 
the entire system of programs (system testing), testing the application with a large amount of 
data (volume testing) and testing all related systems together (integration testing), as well as 
conducting any tests required by the user (acceptance testing).  
Alpha testing involves testing an incomplete or early version of the system, while beta testing 
involves testing a complete and stable system by end- users. Alpha-unit testing, for example, 
is testing an individual program before it is completely finished. Beta-unit testing, on the other 
hand, is performed after alpha testing, when the individual program is complete and ready for 
use by end-users.
