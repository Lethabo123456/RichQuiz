Altering Table Structures 
In this section, you will learn how to change table structures by changing attribute characteristics 
and by adding columns. Finally, you will learn how to copy tables or parts of tables and how to 
delete tables.

All changes in the table structure are made by using the ALTER TABLE command followed by a 
keyword that produces the specific change you want to make. Three options are available: ADD, 
MODIFY, and DROP.  
The basic syntax to add or modify columns is:  
ALTER TABLE table-name  
{ADD | MODIFY} (column-name datatype [ {ADD | MODIFY} column-name datatype] );
