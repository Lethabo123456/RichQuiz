Types of Databases 
A DBMS can be used to build many different types of databases. Each database stores a collection 
of data and is used for a specific purpose and different methods have been used to classify these 
databases.  
The number of users determines whether the database is classified as single user or multiuser. A 
single-user database supports only one user at a time. A single-user database that runs on a personal 
computer is called a desktop database. In contrast, a multiuser database supports multiple users 
at the same time and can be either classified as a workgroup database or an enterprise database.
