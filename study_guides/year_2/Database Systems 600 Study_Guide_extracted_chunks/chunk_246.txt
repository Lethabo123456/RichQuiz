FROM Clause Options 
The FROM clause of the query specifies the table or tables from which the data is to be retrieved. 
In practice, most SELECT queries will need to retrieve data from multiple tables. Through joins, 
the programmer integrates pieces of data to satisfy the users’ information needs.  
Inner joins return only rows from the tables that match on a common value. Outer joins return the 
same matched rows as the inner join, plus unmatched rows from one table or the other.
