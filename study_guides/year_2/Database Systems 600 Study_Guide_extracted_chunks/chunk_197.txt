The main goal of normalization is to eliminate data anomalies by eliminating unnecessary or 
unwanted data redundancies. This goal is achieved by using the concept of functional dependencies 
to identify which attribute (or set of attributes) determines other attributes.  
To get a better idea of the normalization process, consider the simplified reporting activities of a 
construction company that manages several building projects. The base data in Figure 6.1 is 
organized around projects, with each project having a single row to represent the data associated
