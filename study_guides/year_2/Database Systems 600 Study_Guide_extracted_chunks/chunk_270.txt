Relational Set Operators 
In this section, you will learn how to use three SQL operators—UNION, INTERSECT, and 
EXCEPT (MINUS)—to implement the union, intersection, and difference relational operators. 
You can combine two or more sets to create new sets (or relations). That is precisely what the 
UNION, INTERSECT, and EXCEPT (MINUS) statements do.  
UNION, INTERSECT, and EXCEPT (MINUS) work properly only if relations are union-
compatible, which means that the number of attributes must be the same and their corresponding 
data types must be alike.
