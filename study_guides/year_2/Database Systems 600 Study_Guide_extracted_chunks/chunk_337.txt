A transaction log backup, which backs up only the transaction log operations that are not

The database backup is stored in a secure place, usually in a different building from the database 
itself, and is protected against dangers such as fire, theft, flood, and other potential calamities. The 
main purpose of the backup is to guarantee database restoration following a hardware or software 
failure.
