Basic SELECT Queries

table, the RDBMS returns a set of one or more rows that have the same characteristics as a 
relational table. Each clause in a SELECT query performs a specific function. Understanding the 
function of each clause is key to developing the skills to construct queries to satisfy the reporting 
needs of the users. The following clauses will be covered in this chapter (although not in this
