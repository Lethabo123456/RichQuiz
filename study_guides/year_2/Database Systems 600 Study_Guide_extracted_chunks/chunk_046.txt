Data dictionary management. The DBMS stores definitions of the data elements and their 
relationships (metadata) in a data dictionary which also automatically records structural changes. 
The DBMS uses the data dictionary to look up the required data component structures and 
relationships, thus relieving you from having to code such complex relationships in each 
program. This provides data abstraction and removes structural and data dependence from the 
system.
