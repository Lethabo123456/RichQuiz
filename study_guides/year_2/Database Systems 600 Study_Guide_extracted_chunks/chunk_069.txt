Another reason for the relational data model’s rise to dominance is its powerful and flexible query 
language. Most relational database software uses Structured Query Language (SQL), which allows 
the user to specify what must be done without specifying how. The RDBMS uses SQL to translate 
user queries into instructions for retrieving the requested data. From an end-user perspective, any 
SQL-based relational database application involves three parts: a user interface, a set of tables stored
