Deleting Table Rows 
It is easy to delete a table row using the Delete statement. The syntax is:  
DELETE FROM table-name  

 
121 
[WHERE condition-list];  
For example, if you want to delete the product you added earlier whose code (P_CODE) is BRT-
345, use the following command:  
DELETE FROM  PRODUCT  
WHERE   
P_CODE = 'BRT-345'; 
Note that deletion is not limited to a primary key match; any attribute may be use. Likewise with 
updating.
