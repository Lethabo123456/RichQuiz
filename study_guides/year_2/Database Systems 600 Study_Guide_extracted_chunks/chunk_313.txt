Along with a study of user requirements and the existing systems, the analysis phase also includes 
the creation of a logical systems design. The logical design must specify the appropriate conceptual 
data model, inputs, processes, and expected output requirements. When creating a logical design, 
the designer might use tools such as data flow diagrams (DFDs), hierarchical input process output 
(HIPO) diagrams, entity relation- ship (ER) diagrams, and even some application prototypes. The 
database design’s data-modelling activities take place at this point to discover and describe all 
entities and their attributes, and the relationships among the entities within the database.

(modules) for each process within the database environment. All data transformations (processes)
