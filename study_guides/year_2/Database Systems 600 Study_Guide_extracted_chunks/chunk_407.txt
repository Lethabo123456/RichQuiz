Most DBMSs implement indexes using one of the following data structures:  
 
Hash index. A hash index is based on an ordered list of hash values, created using a hash 
algorithm from a key column.  
 
B-tree index. The B-tree index is an ordered data structure organized as an upside-down tree.  
 
Bitmap index. A bitmap index uses a bit array (0s and 1s) to represent the existence of a value 
or condition.
