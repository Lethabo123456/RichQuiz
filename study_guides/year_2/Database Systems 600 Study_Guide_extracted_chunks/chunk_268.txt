Multirow Subquery Operators: ALL and ANY 
So far, you have learned that you must use an IN subquery to compare a value to a list of values. 
However, the IN subquery uses an equality operator; that is, it selects only those rows that are 
equal to at least one of the values in the list. What happens if you need to make an inequality 
comparison ( > or < ) of one value to a list of values?
