There are several techniques that you may choose to apply when analyzing potential value

Techniques to Consider 
The BABOK® Guide recommends using one or more techniques to analyze potential value 
and recommend a solution. These techniques are summarized for you here: 
Acceptance and Evaluation Criteria One best practice is defining measurable acceptance 
criteria for each of your project releases. The criteria define the set of requirements that must 
be met in order for your release and its accompanying capabilities to be considered 
acceptable to its key stakeholders. Test cases will be written to verify the release using this 
defined acceptance criteria.
