A JVM is distributed along with a set of standard class libraries that implement the Java API 
(Application Programming Interface). Appropriate APIs bundled together form the Java Runtime 
Environment (JRE).   
  
Java development process   
The javac command compiles Java source code (.java) into   bytecode (.class).
