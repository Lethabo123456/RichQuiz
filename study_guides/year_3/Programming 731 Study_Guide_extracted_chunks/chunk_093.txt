The if-else-if Ladder    
A common programming construct that is based upon a sequence of nested ifs is the if-else-if ladder. 
It looks like this:   
   
if(condition)   
   
statement;   

else if(condition) statement;   
   
else if(condition) statement;   
...   
else statement;   
   
The if statements are executed from the top down. As soon as one of the conditions controlling the 
if is true, the statement associated with that if is executed, and the rest of the ladder is bypassed. If 
none of the conditions is true, then the final else statement will be executed. The final else acts as 
a default condition; that is, if all other conditional tests fail, then the last else statement is 
performed. If there is no final else and all other conditions are  false, then no action will take 
place.
