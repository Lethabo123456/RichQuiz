1.6.4 Creating Structs 
Create an instance of a struct by using the new keyword in an assignment statement, just as 
you would for a class. In Example 1-2.0, the Tester class creates an instance of Location as 
follows: 

Location loc1 = new Location(200,200); 
Here the new instance is named loc1 and is passed two value

This lesson described what is a class , struct and identified a few differences between class 
and struct types. You learned how to create a struct. You can instantiate a struct either via a 
default constructor or a custom constructor overload that you write. You also saw how to 
implement properties and methods in structs.
