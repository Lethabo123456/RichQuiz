1.2.2 Initializers 
It is possible to initialize the values of member variables in an initializer, instead of having to 
do so in every constructor. Create an initializer by assigning an initial value to a class member: 
private int Second = 20; // initializer 
Assume that the semantics of our Time object are such that no matter what time is set, the 
seconds are always initialized to 20. We might rewrite our Time class to use an initializer so 
that no matter which constructor is called, the value of Second is always initialized, either 
explicitly by the constructor or implicitly by the initializer, as shown in Example 2-4. 
            Minute = dt.Minute; 
            Second = dt.Second;
