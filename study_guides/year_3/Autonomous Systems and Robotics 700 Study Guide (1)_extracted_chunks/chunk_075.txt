2.5.5.4 Image Transformations 
Image transformations are an important aspect of image processing that involve modifying the 
geometry of an image to achieve desired effects or extract useful information. Common 
transformations include scaling, rotating, and cropping. These operations help in preparing 
images for further processing and analysis, such as in applications of machine learning and 
computer vision. 

2.5.5.5 Scaling (Resizing an Image) 
Resizing an image is one of the most basic transformations. It can be crucial for reducing the 
computational load required for processing large images or for making images fit a particular size 
requirement. OpenCV provides the cv2.resize() function for this purpose, which allows you to 
specify the new image dimensions or a scaling factor. 

2.5.5.6 Rotating an Image 
Rotating an image is another common transformation. It can be used to correct the orientation 
of an image or for artistic effects. To rotate an image, OpenCV uses a transformation matrix, which 
can be created using the cv2.getRotationMatrix2D() function. This matrix is then applied to the 
image using the cv2.warpAffine() function.
