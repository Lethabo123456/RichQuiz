6.2.1 Types of Neural Networks Relevant to Robotics 

Type                     Use in Robotics
------------------------------------------------------------------------------------ 
Feedforward NN           Function approximation, energy prediction 
------------------------------------------------------------------------------------
Convolutional NN (CNN)   Vision tasks (object detection, terrain classification) 
------------------------------------------------------------------------------------
Recurrent NN (RNN)       Temporal tasks, e.g., speech, trajectory prediction 
------------------------------------------------------------------------------------
Deep Networks            High-capacity learning for end-to-end control
------------------------------------------------------------------------------------

Convolutional Neural Networks (CNNs) for Visual Navigation 

CNNs excel at extracting spatial features from visual data, making them ideal for: 
• Lane detection in autonomous vehicles 
• Landmark recognition for localisation 
• Obstacle classification from camera feeds
 
The code below demonstrates a Convolutional Neural Network (CNN) model in PyTorch for visual 
navigation in a robot, particularly for obstacle detection and action decision-making.  

import torch 
import torch.nn as nn 
import torch.nn.functional as F 
 
class VisualNavigationCNN(nn.Module): 
    def __init__(self, num_actions=4): 

        super(VisualNavigationCNN, self).__init__() 
        # Input: 3x224x224 RGB image from robot camera 
 
        # Feature extraction layers 
        self.conv1 = nn.Conv2d(3, 32, kernel_size=5, stride=2) 
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, stride=2) 
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, stride=2) 
 
        # Global context 
        self.conv4 = nn.Conv2d(128, 256, kernel_size=3, stride=2) 
 
        # Decision layers 
        self.fc1 = nn.Linear(256 * 13 * 13, 512) 
        self.fc2 = nn.Linear(512, 256) 
        self.fc3 = nn.Linear(256, num_actions)  # [forward, left, right, stop] 
 
        self.dropout = nn.Dropout(0.3) 
 
    def forward(self, x): 
        # Extract visual features 
        x = F.relu(self.conv1(x)) 
        x = F.relu(self.conv2(x)) 

        x = F.relu(self.conv3(x)) 
        x = F.relu(self.conv4(x)) 
 
        # Flatten for decision making 
        x = x.view(x.size(0), -1) 
 
        # Navigation decision 
        x = F.relu(self.fc1(x)) 
        x = self.dropout(x) 
        x = F.relu(self.fc2(x)) 
        x = self.fc3(x) 
 
        return F.softmax(x, dim=1)  # Probability distribution over actions
