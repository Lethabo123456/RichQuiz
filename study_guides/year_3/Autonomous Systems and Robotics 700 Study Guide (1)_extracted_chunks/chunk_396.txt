6.1.2 Unsupervised Learning in Robotics 
While supervised learning requires labelled data, robots often encounter situations where labels 
are unavailable or impractical to obtain. This is where unsupervised learning becomes invaluable, 
allowing robots to discover patterns and structure in raw sensor data. 
Example: Robot Room Classification Using K-Means Clustering 
Consider an autonomous cleaning robot exploring a building for the first time. It needs to 
understand different room types (kitchen, office, hallway) without being explicitly told. Using 
unsupervised learning, the robot can automatically categorize spaces based on sensor patterns. 
import numpy as np 
from sklearn.cluster import KMeans 
import matplotlib.pyplot as plt 
 
# Simulated robot sensor data from different rooms 

# Features: [avg_distance_to_walls, obstacle_density, floor_reflectivity, sound_level] 
sensor_readings = np.array([ 
    # Kitchen readings (closer walls, high obstacles, reflective floor) 
    [2.1, 0.8, 0.9, 0.7], [2.3, 0.7, 0.85, 0.65], [2.0, 0.75, 0.88, 0.8], 
    # Open office (far walls, medium obstacles, carpet) 
    [5.2, 0.4, 0.3, 0.5], [5.5, 0.35, 0.25, 0.45], [5.0, 0.45, 0.35, 0.6], 
    # Hallway (one close wall, low obstacles, hard floor) 
    [3.5, 0.2, 0.7, 0.3], [3.3, 0.15, 0.75, 0.25], [3.7, 0.25, 0.65, 0.35] 
]) 
 
# Apply K-means clustering 
kmeans = KMeans(n_clusters=3, random_state=42) 
room_clusters = kmeans.fit_predict(sensor_readings) 
 
# Robot can now classify new rooms 
new_room = np.array([[2.2, 0.76, 0.87, 0.72]])  # Unknown room 
room_type = kmeans.predict(new_room) 
print(f"New room classified as type: {room_type[0]}") 
OUTPUT: 

The robot encountered a new room with sensor readings: 
• Wall distance: 2.2m (close walls) 
• Obstacle density: 0.76 (high) 
• Floor reflectivity: 0.87 (shiny) 
• Sound level: 0.72 (noisy) 

The algorithm classified it as Type 1, which based on our training data patterns, corresponds to a 
kitchen (close walls, many obstacles, reflective floor). 
Unsupervised learning enables robots to find hidden patterns in data without human labels: 

Key Characteristics: 
• No Labels Required: Robot discovers structure on its own 
• Pattern Discovery: Automatically groups similar situations 
• Adaptability: Can handle new environments without retraining
