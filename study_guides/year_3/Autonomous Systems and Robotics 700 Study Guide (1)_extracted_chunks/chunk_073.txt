that provides a common infrastructure for computer vision applications. Its extensive set of

2.5.1 Basic Image Operations 
When beginning with image processing in OpenCV, understanding how to handle basic operations 
such as reading, displaying, and saving images is crucial. These foundational skills are the stepping 
stones to more complex image manipulation and analysis techniques. 

2.5.5.1 Reading an Image 
To read an image from a file, OpenCV provides the cv2.imread() function. The path to the image 
file is passed as a parameter. It's important to note that cv2.imread() returns an image in BGR 
(Blue, Green, Red) format, which is different from the more common RGB format. This distinction 
is vital when working with image data directly.
