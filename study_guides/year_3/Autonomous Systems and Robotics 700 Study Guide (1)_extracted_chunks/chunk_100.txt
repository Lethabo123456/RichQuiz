The implementation of the algorithm does 4 basic things: 
1. Initialization: Set all distances to infinity except the start node (distance 0)  
2. Main Loop:  
a. Find the unvisited node with minimum distance 
b. Mark it as visited by removing from unvisited set 
c. Update distances to all its unvisited neighbors 
3. Distance Update: If path through current node is shorter than known distance, update it  
4. Path Reconstruction: Use the previous dictionary to trace back the shortest path 
Dijkstra’s algorithm has quite a number of variations, namely, Bidirectional Dijkstra, Dijkstra with 
Early Termination and All-Pairs Shortest Path. The variations focus on specific key points in their 
execution:  
Bidirectional Dijkstra: Searches from both source and target simultaneously, often faster for 
single-pair shortest path 
Dijkstra with Early Termination: Stops when target is reached (useful for single-target queries) 

All-Pairs Shortest Path: Can be extended to find shortest paths between all pairs of vertices
