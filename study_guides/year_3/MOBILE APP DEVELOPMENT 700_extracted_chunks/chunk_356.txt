notifyDataSetChanged() command. If the delete fails, a message is displayed to the user. 
The next step is to code the switch. The user enables deletion by moving the Delete switch to the on 
position. This tells the RecyclerView adapter to display (and enable) the Delete button in the list item 
layout. If the user taps the Delete button, the button’s response to a tap event is executed and the 
contact is deleted from the database and the list. This implementation does not ask the user to confirm 
the deletion, but that functionality could be added. Refer to Listing 6.15 to code the initDeleteSwitch

▪ Lines 5–8—The OnCheckedChange method checks if the switch is on or off. A switch is considered 
on if the isChecked method returns true. The status of the delete switch is then passed to the 
contactAdapter and notifyDataSetChanged is called. NotifyDataSetChanged tells the adapter to
