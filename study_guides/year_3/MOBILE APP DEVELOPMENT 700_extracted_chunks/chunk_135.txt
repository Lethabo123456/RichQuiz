Note 
The values files are used to hold values that are going to be reused in your app. Unfortunately, the 
only way to know what values are available is to open the file and inspect its contents for the value 
you’d like to use. We recommend that when you add values, you name them very clearly and limit the 
number of values you use, to keep it somewhat manageable. Naming clearly is very important because 
Android Studio’s code completion capability will list the value names but not their actual value.
