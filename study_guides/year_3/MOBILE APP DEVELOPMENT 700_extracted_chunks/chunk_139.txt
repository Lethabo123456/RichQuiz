Switch to  the Text view for the layout. Locate the EditText element. Change the default id to 
“@+id/editTextName” so that we have some understanding what data that widget is handling. There 
are two new attributes. The first is android:ems. This attribute sets the displayed size of the layout to 
10 ems. Ems is a size measurement equal to the number of capital Ms that would fit into the control. 
Note: All these attributes can be changed in the Properties section of the Editor on the right-hand 
side, but it is important to develop an understanding of the XML, so we have you do it in the code. 
The second new attribute is android:inputType. This attribute tells Android how you want text handled
