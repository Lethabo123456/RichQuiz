exists, so the onCreate method is not executed and the sort order is thus never changed. 
The solution to this is to place the code that populates the list in the onResume() method. As you saw 
in previous Chapter, the onResume method is executed just before the Activity becomes visible. This 
method will be executed every time the user navigates to the activity. This is an example of where you 
need to move some of the code from the onCreate method to the onResume() method to make sure 
it is executed whenever the activity becomes visible. Use the following steps:
