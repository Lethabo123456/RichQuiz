3.6.3 Priority Scheduling 
Priority Scheduling is a CPU scheduling algorithm that assigns a priority to each process. The CPU 
is allocated to the process with the highest priority. 

1. Preemptive Priority Scheduling: 
 
The CPU can be pre-empted if a higher-priority process arrives. 
 
Example: If a running process has a lower priority than a newly arrived process, the CPU will 
switch to the new process.
