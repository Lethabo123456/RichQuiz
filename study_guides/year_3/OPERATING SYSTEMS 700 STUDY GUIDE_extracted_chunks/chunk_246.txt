Chapter Seven: Windows Operating Systems  
 
7.1. Windows Operating System 
The Windows operating system (OS) is a proprietary software platform developed by Microsoft, widely 
recognized for its graphical user interface (GUI) and usability. It is one of the most popular operating 
systems globally, powering personal computers (PCs), laptops, and enterprise environments. 
Beginning with Windows 95, released in 1995, Microsoft abandoned its reliance on MS-DOS (short for 
Microsoft Disk Operating System) and began developing powerful operating systems, as shown in Table 

7.1. Interestingly, these operating systems have traditionally included an MS-DOS emulator, used from 
the Windows Command Prompt screen, that allows the use of typed commands, which was the 
operational input mode from the early days of Windows.
