ii. Interactive Operating Systems 
Interactive systems allow direct communication between the user and the computer during 
program execution. Users can input data, receive immediate feedback, and interact with running 
programs. Common in desktops, personal computers, and GUI environments. Examples include 
operating systems like Windows, macOS, and Linux distributions. 

Advantages: 
➢ User-friendly and responsive. 
➢ Supports multitasking and real-time decision-making. 
 
Disadvantages: 
➢ Increased CPU and memory demand compared to batch systems. 
➢ Potential for system overload with heavy or simultaneous user activity.
