1.3. Cloud Computing 

Cloud computing enables operating systems to provide remote access to system resources while 
enhancing transaction security. Despite this shift, operating systems remain responsible for 
managing local resources and coordinating data transfer to and from the cloud. The operating 
systems managing cloud resources handle allocation and deallocation on a massive scale. As 
organizations and individuals increasingly migrate diverse resources such as data management, 
file storage, applications, processing, and security to the cloud, this trend is expected to grow. 
However, the core role of the operating system remains consistent: to access resources, whether 
local or remote, and manage the system efficiently. 

1.4. Operating Systems Platforms 
Operating System Platforms refer to the underlying software environments that support the 
operation and management of hardware resources and software applications. They are 
categorized based on their intended use, architecture, and features. Common platforms include: 

1. Desktop Operating Systems. 
2. Mobile Operating Systems. 
3. Server Operating Systems. 
4. Embedded Operating Systems. 
5. Cloud-Based Operating Systems. 
6. Mainframe Operating Systems.
