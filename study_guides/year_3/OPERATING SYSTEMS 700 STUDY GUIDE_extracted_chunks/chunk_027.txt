1.2.6 User Interface 

The user interface (UI) of an operating system is a key and recognizable component. There are 
two primary types: graphical user interfaces (GUIs) and command line interfaces (CLIs). 

• GUIs use pointing devices like a mouse or touch inputs and offer visually rich interaction 
through menus, desktops, and varying formats across different operating systems and 
versions. 
• CLIs require users to type specific commands on a keyboard, providing advanced control 
and functionality for skilled users. Commands can be concatenated to execute complex 
tasks more efficiently than with GUIs. However, CLIs demand precise syntax, accuracy, and 
error recovery skills.
