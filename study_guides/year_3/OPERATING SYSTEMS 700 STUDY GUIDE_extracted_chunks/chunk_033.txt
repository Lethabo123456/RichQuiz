iv. Hybrid Operating Systems 

Combines features of multiple types of operating systems, usually interactive and real-time 
capabilities. Allows both batch processing and interactive user interaction. Examples include 
modern operating systems like Windows and Linux that support real-time applications alongside 
general-purpose use. Supports multitasking, time-sharing, and real-time operations. 

Advantages: 
➢ Flexible and versatile. 
➢ Supports a wide range of applications. 

Disadvantages: 
➢ Complexity in design and resource management. 
➢ Can result in suboptimal performance for specialized tasks.
