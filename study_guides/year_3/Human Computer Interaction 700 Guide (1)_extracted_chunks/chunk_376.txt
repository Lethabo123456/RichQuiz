9.4 Open Source Resources  
 
Open source software refers to source code for components, frameworks, or entire systems that are 
freely available for reuse or modification. Design systems are often released in open source repositories 
for others to access and utilize, such as Microsoft's Fluent Design System. Open source development is a 
community-driven effort, where developers contribute, maintain, and enhance code, which is then shared 
with the community through open source repositories for further development and use. The contributors, 
or committers, are mostly volunteers, although an increasing number of companies are also releasing 
open source code. 

These components are made available for use under licenses that allow anyone to use, modify, and adapt 
the software without the typical copyright restrictions. Many critical software systems that support the 
global digital infrastructure are open source, including the Linux operating system, the Eclipse 
development environment, and the PHP development language. 
For interaction designers, the availability of open source software for designing user experiences is 
becoming increasingly valuable. One example is the design pattern implementation libraries discussed 
earlier. Another prominent example is the Bootstrap framework, released as open source in August 2011, 
which is regularly updated. This framework offers reusable code snippets, a flexible screen layout grid 
that adapts to multiple screen sizes, and a library of predefined patterns such as navigation elements, 
typefaces, buttons, and tabs. The framework and its documentation are available on GitHub, providing 
valuable resources for front-end web development. 

Open source resources require a reliable hosting service to store and make the source code accessible to 
others. Additionally, the hosting service must support a large number of users—GitHub, for example, had 

83 million users in 2022—who will want to build, review, modify, and extend software projects. Managing 
this level of activity requires version control, which allows previous software versions to be saved and 
restored if necessary. GitHub, for instance, uses the Git version control system. 
Communities often form around these hosting services, and submitting code typically requires creating 
an account. Each developer on GitHub, for example, can set up a profile that tracks their activity, enabling 
others to view and comment on their contributions. 

Most hosting services provide both public and private spaces. Code submitted to a public space is 
accessible to anyone in the community, while code in a private space remains closed. The benefit of 
releasing code as open source is that a large community can review, use, and modify it, helping to identify 
security vulnerabilities or inefficiencies, as well as contributing to its enhancement. Other popular open 
source repositories include BitBucket, SourceForge, and GitLab.
