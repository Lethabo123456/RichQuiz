3.5 Interaction Types   
 
The design space can be conceptualized through the various interaction types that define the user 
experience. Initially, there were four primary interaction types: instructing, conversing, manipulating, 
and exploring. A fifth type, responding, was added by Christopher Lueg and others, referring to 
situations where a system initiates a request that the user can respond to, such as Netflix asking if the 
user wants to continue watching. 
Here’s a breakdown of each interaction type: 
• Instructing: The user issues commands to the system, such as typing in commands, selecting 
options, speaking commands, gesturing, or pressing buttons. 
• Conversing: This involves dialogue with a system, often seen in conversational user interfaces 
(CUIs) where users ask questions and the system responds via text or speech. 
• Manipulating: Users interact with virtual or physical objects by performing actions like opening, 
closing, or moving items, relying on their understanding of how objects behave. 
• Exploring: Users navigate virtual or physical spaces. This includes exploring 3D virtual 
environments or moving through physical spaces with sensor-based technologies, like smart 
rooms. 
• Responding: In this case, the system initiates an interaction, and the user decides whether to 
engage, such as receiving alerts from a location-based service. 
These five interaction types are not mutually exclusive, and users may engage with systems in multiple 
ways, depending on the context. They help guide the design of interfaces and provide insight into how 
systems should be built to best support users' needs.
