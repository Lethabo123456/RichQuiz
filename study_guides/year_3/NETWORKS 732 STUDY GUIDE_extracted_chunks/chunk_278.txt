5.3.12 tcpdump 
The tcpdump utility is used to read either packets captured live from a network or packets that 
have been saved to a ﬁle. Although there is a Windows version called windump, tcpdump only 
works on Unix-like operating systems. 

Examples of Using tcpdump 
Use this command to capture traﬃc on all interfaces: 
# tcpdump -I any 
Here is the command to capture traﬃc on a particular interface: 
# tcpdump -I eth0 
And to ﬁlter traﬃc by IP, whether it’s the source or the destination, use this command: 
# tcpdump host 192.168.5.5 

Using the File Transfer Protocol 
You already know that File Transfer Protocol (FTP) is a subset of TCP/IP and that FTP is used for 
the transfer of ﬁles. In recent years, FTP has become a truly cross-platform protocol for 
transferring ﬁles. Because Internet (and thus TCP/IP) use has skyrocketed, almost every client and 
server platform has implemented FTP. Windows is no exception. Its TCP/IP stack comes with a 
command-line ftp utility.
