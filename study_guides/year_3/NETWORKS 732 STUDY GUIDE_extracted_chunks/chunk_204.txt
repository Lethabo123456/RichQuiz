Chapter Five: Network Software Tools and Commands 
 
5.1 Introduction to Network Software Tools 

Specialized tasks require specialized tools, and installing network components is no exception. 
We use some of these tools, such as network scanners, on an everyday basis, but most of the 
software tools I’ll be covering in this chapter are used mainly in the telecommunications industry. 
Still, to meet the CompTIA Network+ objectives and because you’re likely to run across them in 
today’s networking environments, it’s very important that you’re familiar with them. 
To effectively test and troubleshoot networks, it is important to be aware of and know how to 
operate the many different types of tools available for you to use. In this chapter we are going 
over many of the software applications designed for network testing and troubleshooting. 
Knowledge of how to use these tools allows you to locate, troubleshoot, and resolve any 
networking issues you may come across. 

Given a scenario, it is important to use the appropriate network software tools and 
commands. In this chapter we will be elaborating on the following:
