Observing User Behaviour and Human Error 
 
Often, what appears to be a system fault is the result of user error—for example, entering a 
password incorrectly due to Caps Lock being on. Some users may not understand logon 
procedures because they rarely log oﬀ or haven’t received proper training. 

Best Practices for Verifying User Actions: 
 
• Observe the user performing the task in person. 
• Use remote desktop software to watch or control their session (with permission). 
• Speak with the user by phone and have them narrate each action they perform. 
• Ask the user to proceed slowly and describe every keystroke and screen message. 
 
This methodical process reveals user mistakes and, if none are found, provides valuable 
diagnostic clues for deeper troubleshooting (Dean, 2013, p. 603).
