Change Management Systems 
 
Organizations may also use change management systems to track network changes 
methodically. These systems enable personnel to document modiﬁcations aﬀecting network 
performance, security, or conﬁguration. Important changes to record include: 

• Hardware or software upgrades 
• Device additions (e.g., ﬁrewalls) 
• Reconﬁgurations (e.g., VLANs, IP addresses) 
• User rights adjustments 
• Server migrations 
• Procedural changes (e.g., backup scheduling) 
• Vendor transitions (e.g., cloud service providers) 

Although minor changes like user password resets may not require logging, analysts must 
understand their organization's speciﬁc documentation policies (Dean, 2013). 
Proper documentation serves two key purposes: 
 
• It informs others about past issues and resolutions. 
• It records network changes that could aﬀect other services or users. 
 
Ultimately, meticulous documentation supports network stability, security, and eﬃcient 
teamwork across IT functions.
