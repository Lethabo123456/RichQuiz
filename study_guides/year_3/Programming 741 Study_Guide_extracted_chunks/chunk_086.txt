2.8 Methods in the Math Class 
The Math class has a number of predefined static methods you will find helpful. The Math 
class, such as the Console class, is located in the System namespace. This class provides 
constants and methods for trigonometric, logarithmic, and other common mathematical 
functions. The Pow( ) method that you saw previously is a member of the Math class. You 
learned that the first argument to the Pow( ) method is the base, the number to be raised. 
The second argument is the exponent, or the specified power value. Table 2-1 identifies, 
describes, and gives examples of the more commonly used methods from the Math class. The 
signature and the return type are included in the third column.
