1.1.6 Commenting code 
You will often see two forward slashes (//) followed by ordinary text in C# code. These are 
comments. They are ignored by the compiler but are very useful for developers because they 
help document what a program is actually doing. Take, for instance, the following example: 
 
Console.ReadLine(); // Wait for the user to press the Enter key 
The compiler skips all text from the two slashes to the end of the line. You can add multiline 
comments that start with a forward slash followed by an asterisk (/*).
