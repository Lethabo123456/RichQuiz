4.6.4 Extending Interfaces 
It is possible to extend an existing interface to add new methods or members, or to modify 
how existing members work. For example, you might extend ISedan with a new interface, 
IExecutive, which extends the original ISedan interface with methods to count seats: 
interface IExecutive : ISedan 
{ 
void CountSeats() 
} 
Classes are now free to implement either ISedan or IExecutive, depending on whether they 
need the additional functionality. If a class does implement IExecutive, it must implement all 
the methods of both ISedan and IExecutive,  . Objects of that type can be cast either to ISedan 
or IExecutive.  
 
Similarly, you can create new interfaces by combining existing interfaces, and, optionally, 
adding new methods or properties. The new interface will implement all methods and 
properties from the base interface. 
 
interface Irental : ISedan,ICoupe 
{ 
void CountSpareWheels() 
void Drivers() 
 
}
