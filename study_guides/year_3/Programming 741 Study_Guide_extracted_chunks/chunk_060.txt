Example 1-11. Using a while loop 
 
The code in Example 1-11 produces results identical to the code in Example 1-10, but the logic 
is a bit clearer. The while statement is nicely self-contained, and it reads like an English 
sentence: "while i is less than 10, print this message and increment i." Notice that the while 
loop tests the value of i before entering the loop. This ensures that the loop will not run if the 
condition tested is false; thus, if i is initialized to 11, the loop will never run.
